# Dashboard

Live runtime metrics dashboard. Demonstrates `JXRRuntime`, `WorkerPool`, `VirtualFS`, and `MoQTransport`.

```bash
npm install
jxr dev
```

Tabs:
- **Worker Pool** — live task throughput, latency, and worker utilization
- **Modules** — files loaded in the VirtualFS
- **MoQ Transport** — connection state, RTT, bandwidth, and packet counters
